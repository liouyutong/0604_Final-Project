# 程式說明

## 專案概述
本專案目標為建立一個口腔健康影像分類系統，透過 CNN 模型判斷牙齒/口腔照片的健康狀態。專案主要包含資料集、訓練程式與測試評估程式。

## 資料集結構
專案資料集位於 `Dataset/`，包含三個子資料夾：

- `Dataset/Training/`
  - `Images/`：訓練影像檔案
  - `Labels/`：對應 YOLO 格式標註檔案（`.txt`）
- `Dataset/Validation/`
  - `Images/`
  - `Labels/`
- `Dataset/Test/`
  - `Images/`
  - `Labels/`
  - `Test_captions.csv`

### 標註格式說明
每個標註檔為 YOLO 形式，內容為多行：
```
<class_id> <x_center> <y_center> <width> <height>
```
本專案目前會將 `class_id` 轉成三種健康狀態：
- `0`：無異常
- `1`：輕微發炎
- `2`：嚴重發炎

轉換規則由 `YOLO_TO_HEALTH` 字典控制，可根據實際類別映射調整。

## 訓練程式：`train_oral_health_classifier.py`
這個訓練程式負責：

1. 讀取 `Dataset/Training/Images` 與 `Dataset/Training/Labels`。
2. 將 YOLO 標註轉換為健康等級標籤。
3. 建立 PyTorch 資料集與資料載入器，並對訓練集做資料增強。
4. 使用 ResNet50 作為 backbone，替換最後一層輸出為 3 個類別。
5. 進行模型訓練、驗證與 early stopping。
6. 將最佳權重儲存到 `saved_models/oral_health_classifier.h5`。

### 主要設定
- 預設影像尺寸：`224x224`
- 預設 batch size：`16`
- 預設 epoch：`5`（已調整為快速測試）
- 使用裝置：自動選擇 `cuda` 或 `cpu`

### 執行方式
在專案根目錄執行：
```powershell
.\.venv\Scripts\python.exe train_oral_health_classifier.py --dataset_dir Dataset/Training --epochs 5
```
或使用已建立的啟動檔：
- `run_train.bat`
- `run_train.ps1`

## 測試程式：`evaluate_oral_health_classifier.py`
這個測試程式負責：

1. 讀取 `Dataset/Test/Images` 與 `Dataset/Test/Labels`。
2. 將 YOLO 標註轉成健康等級標籤。
3. 使用與訓練同樣的 ResNet50 模型結構載入已儲存權重。
4. 對 Test 資料做分類預測，計算整體準確率。

### 執行方式
```powershell
.\.venv\Scripts\python.exe evaluate_oral_health_classifier.py
```
若要指定模型檔案或測試資料路徑，可加參數：
```powershell
.\.venv\Scripts\python.exe evaluate_oral_health_classifier.py --dataset_dir Dataset/Test --model_path saved_models/oral_health_classifier.h5
```

## 虛擬環境與依賴
專案使用虛擬環境 `.venv`，必要套件包含：
- `torch`
- `torchvision`
- `Pillow`
- `tqdm`
- `numpy`

若尚未安裝，請在虛擬環境中執行：
```powershell
.\.venv\Scripts\python.exe -m pip install torch torchvision Pillow tqdm
```

## 注意事項
- 若你要改成多類別或多標籤分類，請調整 `YOLO_TO_HEALTH` 的映射與 `CLASS_NAMES`。
- 若要進行更精細的測試，可把 `Dataset/Validation` 加入訓練流程或改成更嚴格的評估指標。
- 本說明以當前程式碼為基礎，如程式碼後續修改，請同步更新對應文件內容。
